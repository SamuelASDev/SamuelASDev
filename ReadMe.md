## 🚀 Projetos em destaque

### 🌐 Vértice — Plataforma de portfólios profissionais

Desenvolvi o **Vértice** para criar, personalizar e publicar portfólios profissionais. A plataforma reúne apresentação pessoal, projetos, tecnologias e contatos em uma vitrine responsiva, com um painel para gerenciar conteúdo e aparência sem editar código. Meu próprio portfólio foi publicado nela.

**Principais recursos:** autenticação e verificação de e-mail, isolamento de dados entre contas, editor de conteúdo rico com imagens e vídeos, personalização visual com prévia privada, organização e destaque de projetos, filtros e compartilhamento por links públicos.

**Tecnologias:** PHP 8.2+, Laravel 12, Blade, MySQL, Tailwind CSS, JavaScript, Alpine.js, Tiptap e Vite.

**Destaques técnicos:** autorização com Policies, sanitização de conteúdo, gerenciamento de uploads e testes automatizados em PHP e JavaScript.

🔗 [Acessar plataforma](https://portifolio.froglabs.site) · [Repositório](https://github.com/SamuelASDev/PortifolioSas) · [Conhecer o projeto](https://portifolio.froglabs.site/samuel-abreu-sales-eb72dded-0fee-446e-8b31-a46abf37dc2f/projects/1)

### 📺 Anime Tracker

**Tecnologias:** Laravel 12, PHP, MySQL, Blade, Tailwind CSS e JavaScript.

### 🎮 LoL Dashboard

Sistema de gerenciamento de contas de League of Legends, com integração à Riot Games API, estatísticas, histórico de partidas e acompanhamento de ranking.

**Tecnologias:** Laravel 12, PHP, MySQL, JavaScript e Tailwind CSS.

🔗 [Acessar projeto](https://loldashboard.froglabs.site)

### 📝 Caderno — Aplicativo de Notas

### ⚔️ Entre Terras — Contador de Mortes
